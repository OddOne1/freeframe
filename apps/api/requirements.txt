# not declare `requests` even though faster_whisper/utils.py imports it at
# module scope. It relied on huggingface-hub to bring it in, and declares
# that as `huggingface-hub>=0.13` with NO upper bound.
#
# huggingface-hub 1.0 replaced requests with httpx and dropped it from its
# core dependencies (verified against PyPI metadata: 0.35.3 still declares
