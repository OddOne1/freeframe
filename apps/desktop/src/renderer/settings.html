General

Day boundary time
When "today" starts for the Daily overview. A job finishing before this time counts towards the previous day — so a night shift that runs past midnight stays one day's work. Midnight means plain calendar days.
Live checksum
Hashed while each file streams past during the copy, then compared against every destination read back from disk. Used by every copy — there is no per-job override.
Uploads to a FreeFrame project are not verified by either tier: they do not go through the copy engine at all. Copying the same card to a drive as well is what gets you a checksummed copy.
Finalized checksum
An optional second pass once every file has copied: the source and every destination are read from disk again and hashed with the algorithm below. It is a full extra read of everything, so it roughly doubles the time a job spends hashing. It covers local destinations; a job reading from a FreeFrame project has no local copy to re-read and is skipped.
About the algorithms

Volumes

Show in Volumes
Unticked items disappear from the middle column only. A drive already set as a Source or Destination keeps its tile in that column. Drives are remembered by name, so two drives sharing a name hide together.

Naming Presets

Build the destination folder and file names from fields you define. Values are filled in per job, and everything stays on this machine.
